## AUTISMATH 🌟

**Arquitetura de Inclusão Matemática via Elite Engineering**

O **AUTISMATH** é um software educacional desenvolvido para auxiliar o processo de ensino-aprendizagem de conteúdos matemáticos para educandos com **Transtorno do Espectro Autista (TEA)**. Criado sob os preceitos de **Elite Engineering**, o aplicativo foca em acessibilidade radical e fundamentação científica, eliminando "muletas" tecnológicas para focar na base real do aprendizado.

---

### 🧠 Embasamento Científico e Pedagógico
O desenvolvimento do software é pautado em métodos consolidados no acompanhamento educacional de autistas, fundamentados no **Behaviorismo**:

*   **Método ABA (*Applied Behavior Analysis*):** Utilização de reforçadores positivos para analisar e modificar o comportamento, desenvolvendo habilidades motoras e cognitivas.
*   **Programa TEACCH:** Foco no processamento visual, no apego às rotinas e na previsibilidade através de recursos visuais estruturados.
*   **Suporte Didático:** Baseado em práticas pedagógicas voltadas para a estruturação do pensamento e a agilização do raciocínio dedutivo.

---

### 🛠️ Stack Técnica e Desenvolvimento
O desenvolvimento prioriza a performance e o baixo acoplamento, garantindo uma experiência fluida e sem sobrecarga sensorial:

| Tecnologia | Aplicação no Projeto |
| :--- | :--- |
| **JavaScript (ES6+)** | Arquitetura modular e limpa independente de frameworks. |
| **Google Material Icons** | Interface intuitiva e acessível via CDN. |
| **Canvas Confetti** | Reforço positivo (Método ABA) com alta performance. |
| **Design Industrial** | Estilização minimalista focada em reduzir a carga cognitiva. |

---

### 📈 Resultados e Monitoramento
O sistema permite o monitoramento do desenvolvimento do educando através de **dados observáveis** (acertos e erros). Essa abordagem fornece métricas precisas para que o educador acompanhe a evolução do aluno ao longo do tempo.

### 🚀 Como Clonar e Executar o Projeto

1.  **Clonar o Repositório:**
    ```bash
    git clone https://github.com/FelipeBritoSP10/autismath-logic-core-application
    ```

2.  **Navegar até a Pasta:**
    ```bash
    cd autismath-logic-core-application
    ```

3.  **Executar a Aplicação:**
    O projeto deve ser executado através de um servidor local (ex: **Live Server** no VS Code ou `python -m http.server 8080`) para suporte aos módulos ES6.
